建築技術規則・解釋函令查詢

內政部國土管理署 114年12月版・

使用說明

查詢

  1. 在「關鍵字」輸入要找的詞，多個關鍵字用空白分隔，例如「停車位 寬度」。也可以輸入函令文號，例如 1090812277。
  2. 在「查詢資料」勾選要查建築技術規則條文、解釋函令，或兩個都查。
  3. 需要時再用「編／章」、「條次」、「函令年份」縮小範圍。函令結果上方的條文按鈕可以只看某一條。
  4. 條文卡片的「查看本條解釋函令」會列出該條全部函令；函令卡片的「查看條文」會顯示對應的條文。
  5. 「開啟原書」會在 App 內打開原始 PDF，並跳到該頁，方便核對原文。

注意

  • 內容是用掃描檔文字辨識（OCR）產生，可能有錯字。正式引用前，請依標示的頁碼回原書核對。
  • 「容許辨識錯字」打勾時，4 字以上的關鍵字允許差 1 個字，這類結果以虛線底線標示。
  • 附錄二「停止適用」的函令預設不顯示，可以取消勾選來查看。

iPad 離線版

  • 用 Safari 打開本網址，按「分享」→「加入主畫面」，之後從主畫面的柴犬圖示開啟。
  • 第一次開啟時會把條文、函令和三份原書 PDF（約 50 MB）存進 iPad，右上角顯示「資料已全部存在本機」後，就可以完全離線使用。建議用 Wi-Fi。
  • 「開啟原書」會在 App 內打開 PDF 並跳到該頁，上方有「關閉」和放大、縮小按鈕。
  • 請從主畫面圖示開啟；只在 Safari 分頁裡使用，資料比較容易被系統清掉。

每年更新資料

  1. 國土管理署每年 3 月印行新版，增列前一年的新函令。下載位址：
    https://www.nlma.gov.tw/ch/sglarticle/buildinterp
  2. 在「建築技術規則及解釋函令彙編」一欄下載三份 PDF：「建築技術規則」、「建築技術規則－建築設計施工編(上)解釋函令彙編」、「建築技術規則－建築設計施工編(下)解釋函令彙編」。
  3. 把三份 PDF 交給 Claude，請它重新辨識並產生新的 建技規則函令查詢.db。
  4. 在電腦上雙擊 _原始碼\匯出iPad版.bat，把 _iPad版 資料夾的內容用 GitHub Desktop 上傳（Commit → Push）。
  5. iPad 下次連網時開啟，會自動下載有變動的部分。
